# Supaflow

Enable Supaflow to connect your account through browser OAuth and operate data
pipelines with hosted MCP. Use `/plugin enable supaflow`, then `/plugin reload`.
Start with a read-only account and workspace check. No Supaflow CLI or Docker is
required. Enabling this plugin does not authorize changes to your resources.

For optional execution inside Snowflake, ask to set up the Supaflow Native App.
The CoCo-only setup skill uses your Snowflake SQL connection and guides browser
consent and agent approval; review installation and compute use before changes.
