# Duplicate search: not run

Public-web duplicate search is deliberately not part of contained review. Sending
candidate excerpts to a search service can disclose unpublished information.
Reports explicitly mark this check as not run, never passed. The static catalog
name check is not semantic or near-verbatim duplicate detection.

A future search or corpus-comparison feature needs its own approved data-handling
boundary. Do not use web tools or send candidate text externally from this skill.
